# Asset sources and licenses
## Use this
- Kenney: CC0 UI packs, icons, 2D and 3D kits https://kenney.nl [S142][S143]
- Quaternius: low-poly models; free in games, no redistribution https://quaternius.com [S144][S145]
- game-icons.net: 4,000+ game icons, CC BY 3.0 with author credit https://game-icons.net [S150][S151]
- Lucide: ISC-licensed UI glyphs (Feather-derived icons MIT) https://lucide.dev [S152][S153]
- Phosphor Icons: MIT, 1,248 icons in 6 weights https://phosphoricons.com [S154][S155]
## Concepts
- Licenses read from each site's license page on 2026-10-28. "Roblox OK" below means the license permits upload and monetized use, not that moderation will accept an image. Not legal advice.
- Textures, HDRIs, 3D:
  - ambientCG: CC0 1.0 for all assets including previews; no credit required; use GL normals [S138][S139].
  - Poly Haven: CC0 for HDRIs, textures, models; site logos and renders are not CC0; no credit required [S140][S141].
  - Kenney: CC0; credit optional; do not use Kenney's logo [S142][S143].
  - Quaternius: Quaternius Asset License v1.0 (updated 2026-08-28), not CC0; OK in a finished game with no credit; may not redistribute the assets, even modified, as packs, templates, or stock files [S144][S145].
  - Poly Pizza: unverified, believed per model (CC0 or CC-BY); returned HTTP 403; check each model's badge [S146].
  - OpenGameArt: per asset (CC0, CC-BY, CC-BY-SA, OGA-BY, GPL); CC-BY needs credit, CC-BY-SA forces share-alike, GPL unclear for art; site warns some uploads have licensing problems [S147][S148].
  - itch.io game assets: license set by each creator, no CC0 filter; "free" is a price filter [S149].
- Icons:
  - game-icons.net: CC BY 3.0 (repo notes CC0 for some); credit each author in-game or in the description [S150][S151].
  - Lucide: ISC, Feather-derived icons MIT; keep the license notice in project files [S152][S153].
  - Phosphor: MIT per its homepage repo; keep the notice; homepage rendered only its title to the research session [S154][S155].
- Fonts:
  - Google Fonts: per family OFL, Apache 2.0, or UFL (top-level folder in the google/fonts repo); licenses allow use but Roblox cannot import font files; reference only, use Roblox library fonts via `FontFace` [S156][S157].
  - Builder font: Roblox license limited to Roblox UGC and its promotion; default UI family [S66].
- Creator Store: Roblox Terms of Use and IP guidelines, no per-asset open license; page is client-rendered; prefer Roblox or verified creators and vet every script [S67].
- Before uploading:
  - Record license and source URL in a project credits file.
  - CC-BY: credit the author in-game or in the description.
  - Never upload assets whose license forbids standalone redistribution (Quaternius, most paid packs) as Creator Store items.
  - Link to asset libraries; do not bulk-copy them into the repo.
## Gotchas
- Quaternius assets re-uploaded as free Creator Store models count as redistribution [S145].
- OpenGameArt previews are not covered by the download's license [S148].
- Google Fonts site is client-rendered; license info was verified from the GitHub repo [S157].
